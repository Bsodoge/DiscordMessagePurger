## DiscordMessagePurger

DiscordMessagePurger is a simple winforms application that allows you to delete all messages **YOU** have sent from a specific server or DM.

There is no limit on how many messages you can delete. 

### How to use?
- Install the app via releases.
- Unzip and launch the exe.
- Find your authorization code and enter it.
- Wait for the program to fetch all servers and DMs.
- Select the server or DM.
- Purge them all!


The program icon can be found [here](https://icon-icons.com/icon/shredder-file/252035)
